# gnm-engine — GPU render engine for Kodi on PS4

A small render engine over **sceGnm + sceVideoOut** (no Piglet/OpenGL) for
the Kodi PS4 port. This directory is the test bed that validates the
pipeline later integrated into Kodi.

## Status

**Working on hardware (2026-11-02):** a textured quad with the Kodi splash
(625×625 PNG), centred with the correct aspect ratio, presented through
VideoOut. Per frame: clear, VS/PS `.sb` shaders (compiled offline with
`glslc` + `psbc`), linear RGBA8 sRGB sampler/texture, position/UV VBO,
`DrawIndexAuto(6)`, flip.

Validated pipeline pieces:

- `displayctx` (`sceVideoOut`): 1920×1080, one render target, one flip per
  frame.
- Linear 2D texture uploaded from an in-memory PNG (pitch = padded width).
- Descriptor sets via `gnmDrawCmdSetPointerUserData` (VS: fetch + VBOs;
  PS: texture + sampler).
- Fetch shader generated by `gnmCreateFetchShader` from the `.sb`
  semantics.
- Synchronization with `EventWriteEop` + label and `sceGnmSubmitDone`.

## Build and test

Requirements: OpenOrbis toolchain, `opengnm` and `psbc` under
`/tmp/kodi-ps4` (`./scripts/setup-psbc.sh` recreates them).

```bash
cd tools/gnm-engine
export OO_PS4_TOOLCHAIN=$HOME/ps4sdk/OpenOrbis/PS4Toolchain
export DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1
export LD_LIBRARY_PATH=$HOME/proyectos/kodips4/tools/ssl-compat
make GLSLC=glslc PSBC=/tmp/kodi-ps4/psbc/psbc \
     RUNTIME_MODULE_DIR=$OO_PS4_TOOLCHAIN/samples/graphics/sce_module
# PKG: IV0000-FGNM00010_00-GNMENGINE0000000.pkg
```

Upload with `scripts/console-pkg.sh push ... gnm-engine.pkg`, install it
and launch it on the console. Stage logs go to `/data/gnm-engine.log`.

## Solved pitfalls (do not repeat)

1. **`gnmCreateVertexBuffer` takes a VERTEX count**, not bytes
   (`numelements`). Passing `sizeof(vertices)` corrupts the fetch and hangs
   the GPU (CE-34878-0).
2. The package must include `assets/misc/clear.frag.sb`:
   `initclearutility` loads it at startup; without it the app exits before
   creating the window.
3. Linear textures need a **pitch multiple of 64/8**: the PNG is padded to
   640×632 and the UVs are cropped to the real 625×625 area.
4. `PkgTool.Core` needs `DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1`;
   `pkg_build` needs `LD_LIBRARY_PATH=tools/ssl-compat` (libssl 1.1).
5. Runtime modules (`libc.prx`, `libSceFios2.prx`) are not in
   `$TOOLCHAIN/bin/data/modules`; use
   `$TOOLCHAIN/samples/graphics/sce_module`.
